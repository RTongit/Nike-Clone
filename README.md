# Nike-Clone

A responsive and modern clone of the Nike website, built using React and Vite. This project showcases a sleek user interface, interactive components, and a clean layout, reflecting the design aesthetics of Nike's official site.

## 🚀 Features

- **Responsive Design**: Ensures optimal viewing experience across various devices.
- **Modern UI**: Implements contemporary design principles for an engaging user experience.
- **Fast Performance**: Leveraging Vite for rapid development and optimized builds.
- **Clean Codebase**: Structured and maintainable code for easy scalability.

## 🛠️ Technologies Used

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [ESLint](https://eslint.org/)
- [Tailwind CSS](https://tailwindcss.com/)

## 🧑‍💻 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or later)
- [npm](https://www.npmjs.com/) or [Yarn](https://yarnpkg.com/)

### Installation

1. **Create a folder.Open it with terminal**

2. **Clone the repository:**

   ```bash
   git clone https://github.com/RTongit/Nike-Clone.git
   ```


3. **Navigate to the project directory:**

   ```bash
   cd Nike-Clone
   ```

4. **Install dependencies:**

   ```bash
   npm install
   ```

   or

   ```bash
   yarn install
   ```

### Running the Development Server

```bash
npm run dev
```

or

```bash
yarn dev
```

Open your browser and visit `http://localhost:5173` to view the application.

## 📦 Building for Production

To generate an optimized production build:

```bash
npm run build
```

or

```bash
yarn build
```

The output will be in the `dist/` directory.

## 🧹 Linting
